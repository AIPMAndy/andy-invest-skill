## [1.0.0] - 2026-07-22

### Added
- Initial release of Andy Investment Skill as unified entry point
- Comprehensive README with project overview and philosophy
- Architecture documentation explaining project relationships
- Contributing guidelines with security and compliance requirements
- Integration map for all investment series projects:
  - ai-invest-agent (portfolio management & analysis hub)
  - youzi-trading-skill (short-term trading discipline)
  - changying-index-fund-skill (long-term index investing)
  - FIREClaw (financial independence planning)
  - andy-follows investment module (market intelligence)
- Workflow diagram showing how projects work together
- Clear disclaimers and risk warnings
- MIT License with investment disclaimer

### Philosophy
- Established "investment, not speculation" principles
- Defined AI as assistant, human as decision-maker model
- Emphasized research, discipline, review, and risk control

### Documentation
- README.md: Main entry point and navigation
- ARCHITECTURE.md: Detailed project structure and relationships
- CONTRIBUTING.md: Contribution guidelines and code of conduct
- LICENSE: MIT License with investment disclaimers

## Future Roadmap

### Planned Features
- Investment journal system for decision logging
- Portfolio stress testing under extreme scenarios
- Market cycle analysis and asset rotation framework
- Cross-project data integration for unified analytics

### Not Planned
- Automated trading execution (violates human-decision principle)
- Real-time stock recommendations (regulatory risk)
- Paid signal subscriptions (business model risk)
- Social trading / copy-trading features (legal compliance risk)
